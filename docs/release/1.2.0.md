# cachelane 1.2.0 release checklist

## Release notes

**Fixes (PR #40)**
- **Cache on conversation history restored.** The proxy stripped Claude Code's rolling `cache_control` breakpoint on the last message and never replaced it, so history billed at 1.0x every turn from about request 4. On a head-to-head against realistic Claude Code caching, the old proxy cost 1.166x; 1.2.0 is at parity (1.000x).
- **Pruned-block stub text is stable across turns.** It previously changed ("5123 tokens elided" to "45 tokens elided") and broke the cache at that block.
- **Subscribers keep their 1-hour cache.** Claude Code sends 1h cache markers on Pro and Max plans, and the proxy downgraded them to 5m, so every pause over 5 minutes became a full rebuild. The proxy now keeps the client's tier.
- **Cache-write cost is recorded correctly.** 1h writes were logged as 5m because the nested `usage.cache_creation` split wasn't read.
- **Install size: 140 MB → 246 KB.** The demo video was shipped three times.

**Changes**
- **The proxy is opt-in:** `cachelane install --proxy`. A plain `cachelane install` prints next steps and writes nothing. Upgrading keeps an existing proxy install.
- **`cachelane doctor`** treats the proxy as optional and points to `npx cachelane-audit`.

**New (PR #41)**
- **`npx cachelane-audit`:** where your input tokens went and why the cache rebuilt. Zero dependencies.
- **Claude Code plugin `cachelane`:** a cold-cache guard that warns once per break before a large expired cache is rebuilt.

**Docs**
- The README leads with the audit and the plugin.
- Unsourced savings claims removed (30% to 60%, 90% Less, roughly 80% measured).
- Keepalive documented as not implemented.
- License text fixed to Apache-2.0 on the site.

## Pinned GitHub issue

**Title:** cachelane 1.1.7 and earlier can raise your Claude Code cost on long sessions; please upgrade to 1.2.0

**Body:**
- **What happened:** 1.1.x removed Claude Code's own cache breakpoint on the conversation, so long sessions re-billed their history at full price on every turn.
- **The fix:** 1.2.0 restores it, and a test against realistic Claude Code caching shows parity.
- **Upgrade:** `npm i -g cachelane@latest`. Your existing proxy setup is kept.
- **Check your own sessions:** `npx cachelane-audit`.

## 1.2.1 (republish of 1.2.0)

1.2.0 was published without `dist/` (4 files, no CLI code) because `dist/` is gitignored and the build was skipped. Both packages now have `prepublishOnly` scripts, so `npm publish` always builds first. Release 1.2.1 and mark 1.2.0 as broken:

```bash
npm publish                                   # from feat/release-1.2.0 at version 1.2.1; builds automatically
npm deprecate cachelane@1.2.0 "Broken build (missing dist/). Use 1.2.1 or later: npm i -g cachelane@latest"
```

`cachelane-audit` 0.1.0 had the same problem (no `dist/`). Publish 0.1.1 and deprecate 0.1.0:

```bash
cd packages/audit && npm publish && cd ../..
npm deprecate cachelane-audit@0.1.0 "Broken build (missing dist/). Use 0.1.1 or later."
```

## Maintainer steps (in order)

   ```bash
   npm ci && npm run build && npm publish
   ```
3. Publish `cachelane-audit`:
   ```bash
   npm run build:audit && (cd packages/audit && npm publish)
   npm owner add <aditya-npm-username> cachelane-audit
   ```
4. Deprecate old versions:
   ```bash
   npm deprecate cachelane@"<1.2.0" "1.1.x can raise Claude Code cost on long sessions; upgrade: npm i -g cachelane@latest"
   ```
5. Create the pinned issue above, and a GitHub release `v1.2.0` with the release notes.
6. Deploy the site (Vercel) so the headline and license changes go live.
