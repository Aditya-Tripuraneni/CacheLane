# cachelane 1.2.0 (proxy opt-in, audit-first) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release `cachelane` 1.2.0. The proxy fix from PR #40 ships, the proxy becomes opt-in, and the docs and site lead with `npx cachelane-audit` and the guard plugin.

**Architecture:**
- `install` gains a `--proxy` flag. Without it, the command writes nothing and prints next steps.
- A new `proxyInstalled(env)` helper detects existing proxy installs, so upgrading users keep the proxy.
- `doctor` treats the proxy as optional and points to the audit.
- Copy changes in the README, the website and a release doc.

**Tech Stack:** TypeScript, commander, vitest (all existing).

**Spec:** `docs/superpowers/specs/2026-10-15-cachelane-audit-guard-design.md` (section "Release and existing users"), with two changes the user approved on 2026-10-15:
1. **Default `install`:** writes nothing and prints the plugin and audit steps. The guard ships only as the plugin.
2. **No `cachelane audit` subcommand and no dependency on `cachelane-audit`:** this avoids npm workspaces and a publish-order constraint. `doctor` points to `npx cachelane-audit` instead.

## Global Constraints

- **Existing proxy users are never downgraded silently.** A plain `install` runs the full proxy install when `ANTHROPIC_BASE_URL` (or `ANTHROPIC_BEDROCK_BASE_URL`) already points at the local proxy.
- **`install --proxy` behaves exactly like 1.1.7's `install`.** Output stays a single JSON line.
- **No performance claims without billed-cost data.** Remove "30% to 60%", "90% Less", and the unsourced "roughly 80%" sentence.
- **License text:** Apache-2.0 everywhere.
- **No em dashes in new copy.**
- **Base:** branch `feat/release-1.2.0` from local `main` (PR #41 content) with `origin/fix/cache-tail-breakpoint` (PR #40) merged in.

```ts
/** True when Claude Code already points at the local CacheLane proxy (an existing proxy install). */
export function proxyInstalled(env: NodeJS.ProcessEnv = process.env): boolean {
  const settings = readJsonObject(claudeSettingsPath(env));
  const claudeEnv: JsonObject = isObject(settings.env) ? (settings.env as JsonObject) : {};
  const intended = baseUrlFor(loadConfig(cachelaneConfigPath(env)).proxy.port);
  return claudeEnv.ANTHROPIC_BASE_URL === intended || claudeEnv.ANTHROPIC_BEDROCK_BASE_URL === intended;
}
```

````markdown
# CacheLane

[![Website](https://img.shields.io/badge/website-cache--lane.vercel.app-7c3aed.svg)](https://cache-lane.vercel.app/)
[![License: Apache-2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

> **See where your Claude Code tokens go, and stop paying to rebuild a cold cache.**
>
> Claude Code already caches your conversation well. The expensive moment is coming back to a long session after a break: the cache has expired, and your next message rewrites the whole context at 1.25x or 2x the input price. On one developer's last 30 days, that was **28% of input spend (~$466 at API price)**, across 68 sessions with a 97.9% cache hit ratio.

## Quickstart

```bash
npx cachelane-audit          # where your input tokens went, and why the cache rebuilt
```

Then add the cold-cache guard inside Claude Code:

```
/plugin marketplace add Aditya-Tripuraneni/CacheLane
/plugin install cachelane@cachelane
```

The guard blocks your first message once when you return to a large session (150k+ tokens) whose cache has expired. It shows what continuing, `/compact`, and `/clear` would cost. Send your message again to continue. You are only warned once per break.

Everything runs locally, reads usage metadata only, and has no backend.

## Power mode: the request-rewriting proxy

```bash
npm install -g cachelane
cachelane install --proxy    # MCP server, hooks, and ANTHROPIC_BASE_URL -> local proxy
cachelane doctor
```

The proxy compresses noisy tool output (git, npm, test logs) and prunes stale tool results while keeping Claude Code's cache breakpoints intact. Upgrading from 1.1.x keeps an existing proxy install. 1.1.7 and earlier stripped Claude Code's rolling cache breakpoint and could raise cost on long sessions, so please upgrade.

> ⚠️ **Do not run `cachelane proxy` yourself.** It is started for you. Running it manually collides on port 7332.
````
